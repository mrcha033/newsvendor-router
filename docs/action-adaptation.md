# Encoder 변경 뒤 행동 가치 head의 재학습

정상 형식 문서로 encoder를 추가 학습한 뒤 발생한 판매 질문 누락 20건은 **행동 가치 head를 새 표현에 맞춰 학습하면 회복됐다**. 그러나 생성 Dev의 질문 비용은 늘었고 공개 문서 추출의 기존 하락도 남아, 이 후보로 전체 선택 모델을 교체하지 않았다.

## 원인 분리

앞선 [문서 적용 범위 비교](parameter-contrasts.md)의 `control`은 encoder·구성기를 학습하고 추가 가치 학습을 0회로 고정한 조건이었다. 언어 능력 변화와 별개로, 같은 행동 head가 바뀐 공유 표현을 받게 된다.

이미 측정한 판매 Dev 336건의 첫 상태를 대조했다. 관측 입력, 행동 판단에 전달되는 모수·상태·분포 및 입력 hash가 모두 같았고 가치 head tensor도 전부 같았다. 그런데 20건에서 첫 행동이 질문에서 보류로 바뀌었다. 이는 원가나 수요가 달라져서 생긴 판단 차이가 아니다. 공유 표현 변경이 행동 점수에 영향을 준 경로다.

Train에서도 과거 실제 rollout에서 관측한 동일 상태 928개를 두 모델에 입력했다. 선택 행동이 60개 달랐으며, 이 중 판매 상태는 308개에서 14개가 질문 대신 보류로 바뀌었다. 이 진단의 기존 반환 손실은 과거 부모 정책으로 수집된 값이다. 새로운 정책의 실제 손실로 오해하거나 그대로 재학습 표적으로 재사용하지 않았다.

## 실제 자기 상태에서 가치 학습

[후속 설정](../configs/l40s-research-action-adaptation-v1.json)은 `control`의 encoder·구성기·GRU를 고정하고 `heads.value`만 갱신한다. 원래 입력·환경 주석 파일 6개가 앞선 실행과 byte 단위로 같고 Train·Dev 출처가 분리됨을 확인했다. 기존 Test와 새 판매 출처 27개는 사용하지 않았다.

완전 관측 판매 Train과 원래 생성 Train의 514개 episode에서 현재 모델의 상태·행동으로 rollout을 새로 수행했다. 각 허용 행동을 먼저 실행한 뒤 실제 응답과 최종 손실·질문 비용을 기록한다. 추가 응답 잡음은 기본 평가와 같은 0이며, 정확한 숨겨진 응답 확률을 아는 planner를 모방하지 않는다. 두 번의 수집에서 각각 903개·917개 자기 상태 학습 표적을 얻었다.

각 수집마다 최대 30 epochs, 10 epochs마다 원래 Dev를 평가했다. 선택 점수는 판매·생성 각각에서 공개 보류 비용으로 정규화한 평균 손실의 평균이며, 서로 다른 단위의 원시 손실을 섞지 않는다. 첫 수집의 10번째 epoch가 선택됐고 이후 후보는 모두 보존했다. 가치 head의 tensor 4개만 바뀌었으며 다른 가중치는 정확히 같았다.

| 같은 구성기의 원래 Dev | 재학습 전 | 가치 head 재학습 후 | 고정 질문 |
| --- | ---: | ---: | ---: |
| 판매 필요 요청 후 회복 / 336 | 316 | **336** | 336 |
| 판매 모수가 부족한 채 종료 | 20 | **0** | 0 |
| 판매 불필요한 질문 / 잘못된 발주 진행 | 0 / 0 | 0 / 0 | 0 / 0 |
| 판매 완전 관측 기간 평균 총손실 | 39.0338 | **24.3925** | 24.3925 |
| 생성 60사례 평균 총손실 | **140.3161** | 148.3549 | 181.6758 |
| 생성 누락 모수에 대한 질문 수 | 15 | 20 | 60 |
| 생성 이미 해결된 모수에 대한 질문 | 0 | 0 | 0 |

최종 모수·근거 정확도는 모두 100%였다. 판매의 정확한 경제 손실은 고유 기간 5개 × 7개 조건이고, 질문·회복 지표는 품절 기간을 포함한 336건 전체다. 가치 학습 후에도 판매에서는 고정 질문 정책보다 경제적으로 나아지지 않았다.

생성 손실 증가는 **동일한 충돌 출처 family의 변형 5건**에서 발생했다. 재학습 전에는 보류했고 이후에는 `v`를 질문한 다음 보류했다. 60건 각각의 최종 손실은 전후 같았고, 추가 요청 비용만 평균 8.0388만큼 늘었다. 이를 서로 독립적인 실패 5개나 일반적인 정책 우열로 해석하지 않는다.

공개 문서 Dev 258건도 실제로 다시 실행했다. 모든 출력이 재학습 전 `control`과 정확히 같았다. TAT-QA는 여전히 12/48로 기존 선택 모델의 16/48보다 낮다. 생성 손실 148.3549도 기존 선택 모델의 147.6813보다 크므로 전체 모델 채택 기준은 충족하지 못했다.

학습·평가 시간은 L40S에서 387.07초, 최대 GPU 할당은 1.24 GiB였다. encoder를 고정한 가치 head 학습 비용이며 전체 encoder 학습의 메모리 요구량을 뜻하지 않는다. [모든 후보·실제 rollout·분해·가중치 검증](evidence/research-action-adaptation-results.json)

이번 결과는 구성 정확도와 순차 판단을 함께 평가해야 함을 보여준다. 제어된 문서·매니저 응답의 결과이며 실제 조직 업무에서의 효과나 행동 가치 학습의 보편적인 우월성을 입증하지 않는다. 현재 선택 가중치는 `forecast-v1`로 유지한다.

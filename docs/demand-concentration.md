# 날짜별 수요 배분 가정 점검

작은 GRU의 크기나 출력 head를 늘리지 않고, 날짜별 관측을 학습하는 가정을 점검했다. 기존 날짜별 likelihood는 양의 총수요를 활성 날짜에 균등 simplex 분포로 배분한다. 예를 들어 7일 총수요가 같아도 하루에 판매가 크게 몰리는 경우를 상당히 허용한다. 실제 Train의 완전 관측 기간에서는 날짜별 판매 비중이 이 가정보다 고르게 분포했다.

## Train에서 확인한 차이

현재 유지하는 GRU를 기존 Train 25개 출처와 추가 Train 512개 출처에 적용했다. 추가 출처는 이 GRU를 학습할 때 사용하지 않았지만, 이번 개발에 사용하는 Train이며 새로운 Test가 아니다. 1일·7일 합계 35,772개 예측의 모수·분위수·출처와 관측을 보존했다.

추가 Train의 완전 관측 7일 구간 2,252개 중 1,015개는 선택된 분포의 80% 구간 하한보다 판매가 작았다. 상한보다 큰 경우는 44개였다. 세 분포 후보 모두 비슷한 방향이므로 종류 선택만의 문제로 볼 수 없다. 다만 품절 없는 기간 자체가 낮은 수요를 선택할 수 있다. 이 결과를 전체 잠재 수요의 과대 예측이나 calibration 오류의 크기로 해석하지 않는다.

양의 판매가 있는 날짜의 비중에 대칭 Dirichlet 분포를 적합했다. 모든 날짜가 완전히 관측되고 양의 판매일이 둘 이상인 기간만 사용한다. 출처별 평균 log likelihood에 같은 가중치를 주어 기간이 많은 출처가 추정을 지배하지 않게 했다. 정수 농도 1~8 중 전체 Train은 **4**를 선택했다. 사용한 기간은 2,385개, 출처는 337개다. seed 42의 세 출처 분할에서도 학습 쪽은 모두 4를 선택했고, 제외한 출처의 조건부 배분 log likelihood는 농도 1보다 각각 2.2057·2.0565·1.8858 높았다.

이것은 관측된 판매 비중에 대한 근거다. 완전 관측 기간의 선택 편향이나 시간대별 품절 과정을 해결했다는 뜻은 아니다.

## 구현과 검증

`demand.allocationConcentration="fit"`을 선택하면 각 cross-fitting 분할의 학습 출처에서만 농도를 추정한다. 제외한 출처의 관측으로 농도를 정하지 않는다. 최종 GRU 학습에서는 전체 Train으로 다시 추정하며, Dev는 기존과 같이 분포 종류 선택 head의 epoch 선택에 사용한다. 기본값 1과 기존 aggregate 손실은 유지한다.

정수 농도에서는 품절 좌표를 적분하는 식을 유한 다항식으로 전개할 수 있다. 계수는 관측에서 한 번 계산하고 세 분포에 재사용한다. 잠재 일 수요를 표집하거나 별도 신경망 모수를 추가하지 않는다. 날짜별 정확한 값, 0수요와 품절 하한을 구분하는 기존 처리는 그대로 적용한다.

독립 Gamma 일 수요의 합계와 Dirichlet 배분을 사용한 수치 검사는 날짜별 정확한 밀도·생존확률의 곱을 복원했다. 1일 기존 likelihood와 기울기, 0수요·padding, 혼합 검열의 자동미분, Train 출처 분리도 검사했다. 실제 L40S에서 Train 관측 256개로 64·128·256점 적분을 비교했으며, 64점과 256점의 float32 손실 차이는 0, 기울기 상대 차이는 최대 약 1.05e-8이었다. 보존한 이전 코드와 비교해 농도 1 및 aggregate 손실·기울기가 동일함을 확인했다. 수치 검증은 예측 성능 근거가 아니다.

## 비교 규칙

[고정 설정](../configs/l40s-demand-concentration-v1.json)은 seed 42·43·44, 같은 GRU 초기값, 자료, 학습 횟수와 batch 크기를 사용한다. 비교 대상은 같은 seed의 기존 농도 1 가중치와 현재 유지하는 GRU다. 모든 모델은 같은 농도 4 관측 점수로 재평가하며, 실제 출력 `F`의 CRPS·발주 손실·구간 적중률을 별도로 비교한다. 기존 대조군의 예측이 정확히 같은지도 확인한다.

후보 seed는 42로 고정한다. 기존 GRU보다 7일 CRPS와 비용 비율 1·3·9의 발주 손실이 모두 낮아야 한다. 세 seed 중 둘 이상이 각각 두 대조군보다 CRPS와 평균 발주 손실이 낮아야 한다. 1일 CRPS 악화는 10% 이내, 7일 완전 관측 적중률은 감소하지 않아야 한다. 이 조건을 통과하면 같은 문서 구성기로 질문·발주 rollout을 추가 검증한다. 이번 실험에서 Test는 사용하지 않는다.

Dev는 8개 출처, 1일·7일 각각 264개 예측이다. 정확한 CRPS와 발주 손실은 각각 177개·30개 완전 관측 구간에서만 계산한다. 겹치는 기간과 반복 seed를 독립 관측으로 세지 않는다.

[검증 기록](evidence/research-concentration-checks.json)에 전체 테스트 246개·Ruff·세 자료 출처 검사·30개 수치 smoke를 보존했다. [Train 원시 진단과 검사 코드](evidence/artifacts/demand-concentration-checks.tar.xz)는 35,772개 예측의 원래 모수·분위수·관측을 포함하며 파일별 hash를 대조했다. [학습 당시 소스](evidence/artifacts/demand-concentration-v1-source.tar.gz)도 고정했다. 이 자료가 과거 전체 ModernBERT 가중치나 확장 학습 자료 전체의 공개를 대신하지는 않는다.

## 결과: 주간 조건부 지표 개선, 기존 GRU 유지

L40S의 세 seed 학습은 각각 235.73·231.53·239.69초에 완료됐다. 모든 출처 분할과 최종 Train에서 농도 4를 선택했다. 수요 신경망은 기존 360,716개 파라미터이며, 이번 변경으로 추가한 신경망 파라미터는 없다.

| 완전 관측 Dev | 1일 CRPS | 7일 CRPS | 7일 80% 구간 적중률 |
| --- | ---: | ---: | ---: |
| 기존 사용 GRU | 0.2111 | 2.7732 | 33.33% |
| 새 후보, seed 42 | 0.2330 | 1.2686 | 56.67% |
| 새 후보, seed 43 | 0.2525 | 1.4107 | 43.33% |
| 새 후보, seed 44 | 0.2392 | 1.5242 | 50.00% |

7일 CRPS와 비용 비율 1·3·9의 발주 손실은 세 seed 모두 기존 GRU보다 낮았다. 같은 seed의 농도 1 대조군보다도 7일 CRPS와 평균 발주 손실이 모두 낮았다. 기존 GRU 대비 세 seed 평균 CRPS 차이는 −1.3720이지만, 완전 관측 구간은 **30개·출처 6개**뿐이며 출처 bootstrap 95% 구간 [−2.6395, 0.1033]은 0을 포함한다. 반복 seed를 새 출처로 세지 않는다.

반면 1일 CRPS는 세 seed 모두 기존 GRU보다 높다. 사전 후보 seed 42의 악화는 **10.3783%**로 허용한 10%를 넘었다. 네 채택 조건 중 세 조건을 통과하고 이 조건에 실패했다. 품절을 포함한 7일 관측 264개·출처 8개에서는 동일 농도 4로 계산한 날짜별 NLL도 기존 GRU보다 세 seed 모두 높고 평균 차이는 +1.1473이다. 합계 하한 NLL 역시 악화됐다. 완전 관측의 개선만으로 전체 수요분포가 좋아졌다고 결론 내리지 않는다.

따라서 **기존 GRU를 유지하며 새 후보의 통합 rollout과 Test는 실행하지 않았다.** 일별 악화 한도나 후보 seed를 결과에 맞춰 바꾸지 않는다. [전체 비교·채택 조건·출처별 구간](evidence/research-concentration-results.json)

최종 기존 GRU 재현 검사에서는 CPU thread 조건 차이가 발견됐다. `seed()`가 thread 수를 1로 바꾸지만 과거 CPU 측정은 4개였다. 고정 가중치로 1개 thread에서는 23개 분포에 최대 약 1.21e-5 차이가 재현됐고, 4개에서는 528개 예측의 분포·발주량·분포 모수가 모두 정확히 일치했다. 실행기에 CPU thread 조건을 명시했다. 원래 실패 기록과 별도 완료 기록을 보존했으며 학습을 반복하거나 가중치를 수정하지 않았다. 종료 전 GPU 최대 할당량을 파일로 내보내지 못했으므로 그 값은 결측으로 남긴다.

[공개 원시 결과](evidence/artifacts/demand-concentration-results.tar.xz)에는 세 후보의 작은 GRU checkpoint, Train cross-fitting 손실과 출처 분할, Dev 분포·발주량·관측, 대조군 신원과 로그가 포함된다. 학습 당시 소스와 이후 CPU 조건 수정·완료 스크립트를 각각 보존했다. 기존 전체 ModernBERT·대조군 가중치와 확장 입력 자료 전체는 이 묶음에 포함되지 않는다.

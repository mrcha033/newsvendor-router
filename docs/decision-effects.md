# 구성 수정의 경제적 효과: 기존 Dev 탐색 분석

2026-10-10 실행. [통합 연구계획](research.md)의 첫 분석 단계다. 공개된 parent와 scoped 측정을 다시 분석했으며 모델 추론·학습·Test 평가를 새로 실행하지 않았다. 두 방법 모두 AI를 사용하므로 **AI 도입 효과가 아닌 기존 모수 구성 수정의 효과**다. 현재 분석에 실제 사람 참여자는 없다.

## 자료와 회귀

공개 archive의 hash와 원시 행을 검사해 3,960개 결과 행을 복원했다. 조건별 생성 60사례·판매 336사례와 두 방법, 다섯 문서 조건이다. 추가 누락 mask가 없는 기존 경로를 사용하며 생성 환경의 원래 응답 실패는 유지한다. 여러 문서 조건이 같은 기초 사례를 반복하므로 3,960개를 독립 표본으로 세지 않는다.

짝지은 차이 `ΔY=scoped−parent`에 `ΔY ~ 1 + 문서 조건`을 CPU PyTorch float64로 적합했다. 원래 형식을 기준으로 하는 포화 회귀이므로 계수에서 계산한 조건별 효과는 짝지은 평균 차이와 같다. 효과의 경제적 분해·악화 사례·출처 의존성을 함께 조사하는 탐색 분석이며 회귀가 새로운 인과 식별을 추가하지 않는다. [고정 명세](../configs/research-economics-v1.json) · [분석 코드](../scripts/analyze_decisions.py) · [전체 수치](evidence/research-economics-results.json)

14개 종속변수·분모 조합을 각각 분석했다. 정확도·질문 횟수·발주 성공 여부를 총효과의 사후 통제 또는 제외 기준으로 사용하지 않았다. 품절로 정확한 손실이 없는 사례는 질문·상태 지표에는 남긴다.

## 판매 손실의 분해

정확한 손실은 조건별 **35사례·5개 기간·4개 출처**다. 아래 요청 비용도 동일한 35사례에서 계산해 종료 손실과 분모를 맞췄다. 음수는 수정 후 손실이 낮아졌다는 뜻이다. 종료 손실에는 기존 보류·잘못된 진행의 비용이 포함되어 있으므로 순수한 발주량 오차 감소로만 해석하지 않는다.

| 문서 조건 | 평균 총손실 차이 | 종료 손실 차이 | 요청 비용 차이 | 한 출처 제외 시 총손실 차이 범위 |
| --- | ---: | ---: | ---: | ---: |
| 원래 형식 | 0.0000 | 0.0000 | 0.0000 | [0.0000, 0.0000] |
| 다른 상품 | -26.2007 | -16.4894 | -9.7113 | [-37.9441, -9.3820] |
| 다른 기간 | -56.1353 | -47.7830 | -8.3523 | [-90.2036, -25.5524] |
| 구버전 | -95.3263 | -83.8772 | -11.4491 | [-115.3294, -78.0118] |
| 서술 순서 | 0.0000 | 0.0000 | 0.0000 | [0.0000, 0.0000] |

세 혼입 조건은 어느 한 출처를 제외해도 총손실 차이의 부호가 유지됐다. 그러나 출처가 네 개뿐이고 이미 사용한 Dev이므로 이를 모집단의 유의한 효과나 신뢰구간으로 해석하지 않는다. 출처를 동일하게 가중한 결과도 전체 수치에 보존한다.

다른 상품 조건의 종료 손실 감소는 35사례 중 **1건**에서 발생했다. 그 출처를 제외하면 종료 손실 감소는 0이 되고 총손실 감소에는 요청 비용 효과가 남는다. 다른 기간·구버전 조건의 종료 손실 감소 사례도 각각 **3건·6건**이다. 큰 평균 효과가 모든 발주량을 고르게 개선했다는 뜻은 아니다.

## 질문과 악화 사례

불필요한 질문은 품절 조건까지 포함한 336사례·8개 출처·48개 기간에서 측정한다. 세 혼입 조건의 사례당 평균 감소는 각각 **0.8185·0.7857·0.8512회**다. 모든 출처를 하나씩 제외한 비교에서도 평균 감소 방향이 유지됐다. 이 분모의 질문 비용을 위 35사례의 종료 손실에 더하지 않는다.

생성 환경은 조건별 60사례·12 family다. 평균 총손실은 감소했지만 일부 사례는 악화됐다. 판매 환경과 다른 손실 정의이므로 수치를 합치지 않는다.

| 문서 조건 | 평균 총손실 차이 | 개선 사례 | 동일 사례 | 악화 사례 |
| --- | ---: | ---: | ---: | ---: |
| 원래 형식 | 0.0000 | 0 | 60 | 0 |
| 다른 상품 | -242.3009 | 30 | 23 | 7 |
| 다른 기간 | -210.3657 | 31 | 20 | 9 |
| 구버전 | -261.7477 | 30 | 20 | 10 |
| 서술 순서 | 0.0000 | 0 | 60 | 0 |

평균 개선은 전 사례의 개선이나 최적 질문 정책을 뜻하지 않는다. 근거가 복구된 뒤에도 같은 행동 head가 질문 비용을 경제적으로 관리하는지 별도 검증해야 한다. AI가 만든 정보 상태와 후속 행동의 결합이 연구 대상인 이유다.

## 수리 모형의 수치 확인

연속 균등수요의 내부해 여섯 조건에서 발주량 오차의 이차 손실식과 부족 비용에 대한 임계 분위수 민감도를 확인했다. 수치 차분과 해석식이 일치했다. 이는 제시한 수식의 구현 확인이며 학습 AI의 효과 또는 모든 이산·경계 조건에 대한 검증이 아니다.

## 재현과 제한

공개 자료·소스만 별도 디렉터리에 복사하고 원래 작업 소스·결과·네트워크 접근을 차단해 재실행했다. 3,960행의 출력 바이트, 14개 분석, 6개 수치 항등식 검사와 입력·소스 hash가 일치했다. Git commit·실행 시각처럼 실행 환경에 속한 항목은 분석 결과의 동일성 비교에서 제외했다.

```sh
uv sync --frozen
uv run python scripts/analyze_decisions.py \
  --config configs/research-economics-v1.json \
  --output results/decision-effects-reproduction
```

현재 소스의 재현 스냅샷·입력에서 추출한 결과 행·등록 명세·보고서·검증 로그는 [분석 보존 자료](evidence/artifacts/research-economics-v1.tar.xz)에 있다. 원본 입력은 기존 [문서 비교 자료](evidence/artifacts/parameter-decoding-records-v2.tar.xz)와 [전체 Dev 경로](evidence/artifacts/parameter-decoding-dev-raw-v2.tar.xz)를 사용한다. 원시 행과 회귀식은 결과가 유리해지도록 재선택하지 않았다.

기존 Dev의 사후 탐색, 적은 독립 출처, 생성 문서·경제 조건·매니저 응답이라는 한계가 남는다. 출처 제외 범위는 신뢰구간이 아니며 p값·신뢰구간은 보고하지 않는다. AI 사용×질문 허용의 후속 2×2 비교와 새 출처 확증은 아직 미실행이다.

# 비AI 기준선 × 매니저 질문 허용 비교

2026-10-10. **비AI 기준선을 구현하고 Train에서 검증한 뒤, 고정 AI와 네 조건을 L40S에서 실행했다.** 원래 문서에서 질문을 허용할 때 평균 총손실은 비AI 72.1592, AI 20.9941이었다. 다른 상품·기간 문서가 섞이면 AI의 상태 구성이 규칙보다 나빴으며 질문으로 회복했다. 이 결과는 작은 기존 Dev의 탐색 비교다.

## 무엇을 비교했나

| 조건 | 문서·판매 정보 처리 | 질문 |
| --- | --- | --- |
| A0H0 | 문서 규칙 + 비신경망 수요 추정 | 금지 |
| A0H1 | 같은 비AI 경로 | 허용 |
| A1H0 | 고정 ModernBERT-base + 수요 GRU | 금지 |
| A1H1 | 같은 AI 경로 | 허용 |

비AI 경로는 관측 문서의 상품·기간·버전을 확인하고 묶음 가격÷수량, 환불액−수수료 등을 계산한다. 충돌·누락을 유지하며 숨겨진 정답 구성기를 호출하지 않는다. 수요는 과거 판매의 겹치지 않는 7일 합계로 고정된 0 질량 포함 로그정규분포를 추정한다. 최근 최대 84일, 최소 28일, 주간 품절 구간은 하한 관측으로 두고 정규화된 검열 likelihood와 약한 모수 규제를 사용한다. 고정 설정과 한계는 [config](../configs/ai-comparison-v1.json), 구현은 [conventional.py](../src/newsvendor/conventional.py)에 있다.

AI는 공개 recovery-v1 가중치와 `scoped` 구성 경로다. 두 방법은 같은 관측 입력, 공통 optimizer, 질문 예산·비용·응답 환경을 쓴다. 정책은 유효한 모수가 갖춰지면 계산하고, 부족하면 비용이 가장 낮은 미확정 항목을 한 번씩 묻는다. 동률 순서는 c·p·v·b다. H0에서는 질문 없이 계산 또는 보류한다. **학습한 행동 가치 정책의 효과는 이 비교의 대상이 아니다.**

비AI 경로는 한 종류의 전통적 기준선이다. 모든 통계적 수요 모형의 최선 성능을 대표하지 않는다. GRU는 여러 출처로 학습했고 비AI 수요 추정은 해당 과거 이력과 고정 규제를 사용하므로, 차이를 언어 encoder만의 기여로 해석할 수 없다.

## 자료와 실행

- 공개 보존 자료에서 Train 154사례·13출처의 네 조건, 616경로를 먼저 검증했다. 19.61초가 걸렸다. 통과 조건은 입력·출처·유한 출력·균형 검증이며 AI의 우월성이 아니다.
- Train과 출처가 겹치지 않는 기존 Dev 336사례·8출처를 원래 문서, 다른 상품, 다른 기간, 구버전, 환불 서술 순서의 다섯 조건으로 평가했다. 네 방법을 합쳐 6,720경로, L40S 232.31초였다. 최대 GPU 할당은 0.6483 GiB다. 추가 신경망 학습은 하지 않았다.
- 주 분석은 관리자 선호 b가 이미 선택된 240사례다. 질문·상태 지표는 이 240사례·8출처, 정확한 발주 손실은 **25조건·고유 기간 5개·출처 4개**다. 미선택 b의 96사례·정확한 손실 10조건은 별도 보조 분석으로 남겼다.
- 품절 판매를 잠재 수요 정답으로 대체하지 않았다. 정확한 손실을 계산할 수 없는 사례는 네 조건에서 함께 제외하고 상태·질문 평가에는 남겼다.
- 기존 Test와 이미 평가한 27개 출처 holdout을 다시 추론하지 않았다. 실제 사람 참여자는 0명이다.

## 결과

다음은 주 분석의 평균 **총손실=실제 출력 발주량의 과잉·부족 손실 또는 보류 비용+질문 비용**이다. 모든 셀의 분모는 같은 25조건이다. 생성한 경제 모수가 연결된 과거 판매 평가이며 기업의 원화 손익이 아니다.

| 문서 조건 | 비AI·질문 금지 | 비AI·질문 허용 | AI·질문 금지 | AI·질문 허용 |
| --- | ---: | ---: | ---: | ---: |
| 원래 문서 | 409.3229 | 72.1592 | 399.0899 | 20.9941 |
| 다른 상품 혼입 | 409.3229 | 72.1592 | 495.5962 | 26.9413 |
| 다른 기간 혼입 | 409.3229 | 72.1592 | 495.5962 | 26.9413 |
| 구버전 혼입 | 409.3229 | 72.1592 | 495.5962 | 26.6111 |
| 환불 서술 순서 변경 | 409.3229 | 72.1592 | 399.0899 | 20.9941 |

원래 문서에서 최종 모수·근거 정답률은 네 조건 모두 100%다. 이 정답률은 올바른 누락 판단도 맞은 것으로 세므로, 질문 금지 상태에서 값이 모두 채워졌다는 뜻은 아니다. H0의 80%는 누락 때문에 보류한다. 따라서 큰 질문 효과에는 보류를 해소하는 효과가 들어 있다.

다른 상품·기간·구버전에서 비AI 규칙의 모수·근거 정답률은 100%다. AI의 초기 모수 정답률은 85.00~85.31%, 질문 없는 최종 근거 정답률은 81.67~82.08%다. 질문 허용 뒤 최종 모수·근거는 100%로 회복하지만 불필요 질문이 사례당 0.5875~0.5917회 발생한다. 비AI는 이 조건에서도 불필요 질문이 없다. 이는 정형 생성 문서에서 규칙의 장점이 크다는 결과다.

원래 문서에서는 c·p·v·b와 질문이 같으므로 AI의 낮은 발주 손실은 두 경로의 수요 추정 차이에서 나온다. 문서 혼입에서 질문을 금지하면 AI 손실이 비AI보다 **86.2733 높다**. 평균 우위와 악화 조건을 함께 기록한다.

## 회귀와 해석 범위

각 문서 조건·선호 층 안에서 사례 고정효과와 A·H·A×H를 CPU PyTorch float64로 추정했다. 같은 사례의 네 셀 차이를 회귀로 표시한 것이다. 원래 문서의 계수는 A −10.2330, H −337.1636, A×H −40.9321이다. 질문이 허용된 경우 AI−비AI 효과는 **−51.1651**이며, 출처를 동일하게 가중하면 −56.1853이다.

출처를 하나씩 제외한 효과는 −64.5522~−35.4852다. 이는 신뢰구간이 아니다. 정확한 손실의 25조건 모두 AI가 낮았지만 고유 수요 기간은 다섯 개뿐이다. 반복 행을 독립 표본 25개로 간주하지 않는다. 이미 개발에 사용한 Dev와 소수 출처이므로 p값·신뢰구간·일반적 AI 도입의 인과 효과를 주장하지 않는다. 사람의 AI 수용 효과는 [참여자 실험](human-study-guide.md)에서 따로 측정한다.

## 재현

GPU 없이 공개 원시 행의 회귀·셀 평균·출처 효과를 다시 계산할 수 있다. 압축과 모든 member hash를 먼저 검사한다.

```sh
uv run python scripts/analyze_ai.py --output results/ai-reanalysis.json
```

[공개 bundle](model-bundle.md)을 복원하고 CUDA PyTorch 환경에서 실행한다. 출력은 새 경로를 사용한다. Train 보고서와 동일한 구성·소스 hash가 있어야 Dev를 실행할 수 있다.

```sh
export CUDA_VISIBLE_DEVICES="$NEWSVENDOR_GPU_UUID"
export CUBLAS_WORKSPACE_CONFIG=:4096:8
.venv-l40s/bin/python scripts/compare_ai.py --stage train \
  --bundle /path/to/composed-model --output results/ai-rerun/train
.venv-l40s/bin/python scripts/compare_ai.py --stage dev \
  --train-report results/ai-rerun/train/report.json \
  --bundle /path/to/composed-model --output results/ai-rerun/dev
```

[원시 기록 압축](evidence/artifacts/ai-comparison-v1.tar.xz)은 관측 입력·별도 환경·모든 경로·결과·revision·hash를 보존한다. [결과와 검증 metadata](evidence/research-ai-comparison-results.json)에 파일별 hash와 조건별 분석이 있다. 최초 재현 실행의 경로 설정 오류는 보존하고 수정 후 다시 검증했다. 별도 디렉터리에서 원래 작업 소스·자료·결과와 네트워크 접근을 막고 출처별 한 사례×5문서×4조건, **160경로의 출력·상태 hash가 모두 일치**했다.

상태·질문 평균은 240사례, 총손실 평균은 25조건이다. 비용을 분해하려면 원시 행에서 완전 관측된 같은 25조건만 선택한다. 240사례의 요청 비용 평균을 25조건의 발주 손실에 더하지 않는다.

# 계산할 숫자를 함께 고르는 작은 head

**새 가중치를 채택하지 않고 기존 `recovery-v1`을 유지한다.** Train 내부의 개선이 원래 Dev에서 유지되지 않아 세 후보 모두 사전 기준을 통과하지 못했다. 아래 코드는 선택적으로 실행하는 연구 경로다.

문서의 계산 답을 구성할 때 두 숫자를 각각 선택하던 경로에, **두 숫자의 순서와 서로의 관계를 함께 평가하는 54,657 파라미터 head**를 추가했다. 같은 ModernBERT와 같은 관측 후보를 사용하며, 연산을 실행하는 계산기·모수 상태·수요 GRU·매니저 행동 head는 그대로다. 범용 도구 절차를 추가한 실험이 아니다.

## 변경한 부분

기존 모델이 예측한 각 피연산자의 상위 5개 후보로 최대 25개 순서 있는 조합을 만든다. 새 head는 질문의 표현, 두 원문 숫자의 표현, 같은 표·행·열인지와 위치 차이, 기존 선택 점수를 받아 조합의 점수를 보정한다. 원문 위치와 숫자 값은 그대로 유지하고 계산기가 선택된 식을 실행한다. 단일 값 복사는 첫째 후보만 비교한다.

정답 숫자를 후보에 강제로 넣지 않는다. 현재 관측한 원문 밖의 값을 생성하거나, 숨겨진 응답 가능성·평가 정답을 입력하지 않는다. 연산 종류가 틀렸거나 정답 숫자가 상위 후보에 없는 경우, 복잡한 식·여러 답·개수 문제는 이 head만으로 해결되지 않는다. 그런 사례를 전체 점수의 분모에서 제외하지 않는다.

마지막 보정 층을 0으로 초기화하여 원래 순서와 동률 처리를 보존했다. 실제 Train 입력 6,232건에서 추가 학습 전의 전체 추출 결과가 기존 경로와 같았다. 모델의 일반 학습 objective에도 손실을 연결했으며 encoder와 새 head 모두에 gradient가 전달되는지 검사했다. 이번 비교에서는 추가 모듈의 영향을 분리하기 위해 **이미 학습한 encoder·fusion·기존 다른 head·GRU를 고정**했다.

## 같은 부모에서의 L40S 비교

공개 TAT-QA 계산 Train 5,492건과 생성 Newsvendor Train의 실제 관측 상태 740건을 사용했다. 후자는 원가·판매가·잔존가치·부족 비용 2,960개 필드다. 공개 계산과 발주 모수의 총 학습 가중치를 같게 두고, 두 조건에 같은 사례와 같은 batch 순서를 제공했다.

원래 Train 출처를 나눠 학습 시점을 선택했다. 내부 선택 자료는 공개 계산 1,087건, 발주 필드 560개다. 부모 encoder가 이미 본 Train 출처이므로 이 점수를 독립 일반화 성과로 해석하지 않는다. 발주 값과 근거의 정답 수를 유지하는 후보 중 엄격 계산 정답 수를 먼저 비교하고, 동률이면 내부 손실을 사용했다. 학습 전 epoch 0도 선택 후보에 포함했다.

| 조건 | 학습 파라미터 | seed 42 | seed 43 | seed 44 |
| --- | ---: | ---: | ---: | ---: |
| 추가 학습 전 | 0 | 454 | 454 | 454 |
| 기존의 독립적인 두 숫자 포인터 재학습 | 131,072 | 458 | 460 | 461 |
| 숫자 조합을 함께 평가 | 54,657 | 493 | 497 | 495 |

대표 seed 42의 내부 결과는 기존 오답 43건을 고치고 기존 정답 4건을 틀린 것으로, 순증은 39건이다. 모든 개별 사례가 개선된 것은 아니다.

분모는 모두 같은 내부 Train 1,087건이다. 조합 head의 선택 epoch는 11·15·10이며, 발주 값 560/560과 지원 가능한 기존 피연산자 근거 478/478을 유지했다. 이 근거 채점은 기존 Train 주석 어댑터가 연결한 후보를 기준으로 하며 실제 조직 문서의 근거 정확도를 뜻하지 않는다.

세 seed 모두 미리 정한 조건을 통과해, 선택한 epoch를 바꾸지 않고 전체 Train에 다시 적합했다. 전체 공개 계산 Train의 엄격 정답은 부모 2,331/5,492에서 2,552·2,585·2,554건으로 변했다. 발주 필드 채점은 전부 부모와 같았다. 필드 진단에는 부모부터 있던 값 채점 불일치 1건이 있어 2,959/2,960이며, 지원 가능한 피연산자 근거는 2,298/2,298이다. 이를 실제 최종 발주 모수 점수와 혼합하지 않는다.

관측 표현 준비 116.65초, 여섯 내부 학습 조건 67.41초, 세 seed의 전체 Train 재학습 37.21초였다. 합계 221.27초는 고정 encoder 표현을 재사용한 학습 비교 시간이며 전체 모델 재학습이나 운영 지연이 아니다.

## 실제 질문·발주 경로의 평가

각 후보가 직접 만든 모수 상태에서 다음 질문과 발주를 선택한다. 후보 사이에 구성된 상태를 공유하지 않는다. 완전히 같은 관측 입력의 고정 encoder 출력만 재사용하고, 모델을 직접 호출한 결과와 정확히 일치하는지 검사한다.

Train은 생성 360건과 완전 관측 판매 22기간의 154조건이다. 판매는 네 모수의 응답 유무 16가지 조합을 모두 실행하고, 누락률 0·10·20%의 기대 손실을 계산한다. 질문 순서가 응답 난수를 바꾸지 않는다. 모든 고정 seed가 모수·근거·상태·유형, 손실, 불필요한 질문과 정상 응답에서의 회복을 유지해야 원래 Dev로 진행한다.

첫 순차 실행은 고정 응답 조건 API가 Dev만 허용하여 첫 Train 판매 조건에서 중단됐다. 이전 실행과 소스를 보존한 뒤 Train 지원만 추가했다. Cal/Test와 비판매 입력은 계속 거부하며, 응답 조건이 모델 입력에 들어가지 않고 질문 순서가 응답을 바꾸지 않는 검사를 Train·Dev 모두에 적용했다. 신경망의 계산과 학습 가중치는 바뀌지 않았다.

세 후보의 실제 Train 결과는 부모와 모두 같았다. 생성 총손실 150.5491, 판매 누락률 0·10·20%의 총손실 45.7155·111.5455·175.4615였다. 모든 모수·상태·유형·근거 및 질문·회복 기준을 통과했다. 이 Train 평가에서는 생성 경로의 기본 응답 조건을 사용했으므로, 과거 다른 응답 표본의 Train 절대 손실과 직접 비교하지 않는다. 비교하는 네 모델 사이의 조건은 같다. 네 모델의 총 경로는 11,296개이며 고유 판매 기간 수를 늘린 것은 아니다. 실행 시간은 312.36초였다.

## 고정 Dev 결과와 채택 결정

같은 후보를 그대로 원래 공개 문서 Dev 258건, 생성 Dev 60건, 판매 Dev 336조건에서 비교했다. 공개 TAT-QA의 분모 48건에는 지원하지 않는 식·여러 답·개수 문제도 그대로 포함한다.

| 모델 | TAT-QA 엄격 정답 | 반올림 진단 정답 | 생성 총손실 | 판매 총손실, 무누락 |
| --- | ---: | ---: | ---: | ---: |
| 부모 `recovery-v1` | 16/48 | 22/48 | 147.6813 | 24.3925 |
| 조합 head, seed 42 | 15/48 | 21/48 | 147.6813 | 24.3925 |
| 조합 head, seed 43 | 16/48 | 22/48 | 147.6813 | 24.3925 |
| 조합 head, seed 44 | 16/48 | 22/48 | 147.6813 | 24.3925 |

판매 응답 누락 10%·20%의 손실도 모든 모델에서 71.8147·117.8583으로 같았다. 정확한 판매 손실은 **완전 관측 기간 5개·출처 4개의 35조건**에 한정한다. 전체 336조건의 모수·상태·근거·질문 진단과 이 손실의 분모를 섞지 않는다. 다른 공개 과제의 점수도 모두 같았다.

Train과 Dev의 총 33,040개 원시 경로를 전수 대조했다. 모든 후보의 행동 순서·발주량·요청 비용·종료 손실은 부모와 같았다. 이 경로 수는 같은 사례를 모델과 응답 조건별로 반복한 수이며 독립 표본 수가 아니다. Dev 비교에는 528.10초가 걸렸다.

**모든 고정 seed가 엄격 공개 정답을 개선해야 한다는 기준을 충족하지 못했다.** 대표 seed 42를 다른 seed로 바꾸거나, Dev를 보고 epoch·점수 보정 강도·계산 반올림을 선택하지 않았다. 일반화한 정확도 향상이나 Newsvendor 손실 개선을 주장하지 않는다. 현재 선택 가중치, 수요 GRU, 가치 정책은 그대로다.

## 확인한 오류와 한계

대표 후보는 Dev 답 5개를 바꿨지만 오답을 고친 사례는 없고, 기존 정답 1개가 오답이 됐다. seed 43은 1개를 고치고 1개를 틀렸으며, seed 44는 정답 여부가 바뀌지 않았다. 이는 작은 개발 표본에서 관측한 결과이며 일반적인 우열의 통계적 증명은 아니다.

확인된 퇴행은 기간 조건이었다. 2019년과 2018년의 주당순이익 차이를 묻는 사례에서 기존 `1.54 − 1.16 = 0.38`이 `0.77 − 1.54 = −0.77`로 바뀌었다. 새 후보는 같은 행의 2017년과 2019년 셀을 선택했다. 같은 행·열 등 위치 정보만 추가해도 질문의 연도와 선택 순서가 보존된다고 볼 수 없다.

또 다른 변경 사례에는 세 숫자의 평균이 정답식인 문제가 있었다. 현재 두 피연산자 head는 그 식 자체를 표현하지 못한다. 연산 종류·추출 방식·단위 오류도 이 실험에서 고정한 부분이다. 위 사례는 평가 종료 후의 진단이며 이번 학습에 다시 넣거나 Dev 재선택에 사용하지 않았다.

공개 숫자 추출, 수요 calibration, 경제 가치 학습의 추가 이점과 보호된 생성 Test 기준은 여전히 남아 있다. 과거 Test 243.6274를 이 후보의 결과로 옮겨 적지 않는다. 이번에 Test와 별도 27개 출처 holdout의 추론은 실행하지 않았다. 통제 발주 문서와 매니저 응답에서 지표가 유지됐다는 사실을 실제 조직 업무의 효과로 해석하지 않는다.

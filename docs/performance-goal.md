# 연구 평가와 완료 기준

2026-10-10 갱신. 현재 목표는 [통합 연구계획](research.md)의 수리 모형·실험·회귀로 AI 정보처리와 매니저 질문의 경제적 효과를 설명하는 것이다. 유의한 양의 효과를 얻는 것을 완료 조건으로 삼지 않는다.

## 현재 기준

| 항목 | 확인할 내용 |
| --- | --- |
| 수리 모형 | 목적함수·정보 집합·사실과 선호·발주 제약·질문 비용·응답 모형의 가정을 명시하고 수치 확인 |
| 비교군 | 전체 AI 도입, 구성 기능 수정, 질문 허용, 학습 가치 정책의 효과를 구분 |
| 식별 | 같은 사례·응답 조건 비교, 사전 환경 변수와 처치 후 결과 구분, 효과 해석의 범위 명시 |
| 표본 | 독립 출처·기간·반복 행의 분모 구분, 검열 수요 처리, 이미 본 Dev의 탐색 표시 |
| 성과 | 실제 출력 q의 손실과 질문 비용·보류·위반·회복, 악화 사례와 영효과 포함 |
| 회귀 | 사전 명세·원시 행·출처 민감도·재현 가능성; 확증에서는 적절한 표본과 불확실성 |
| 재현·검증 | revision·hash·분할·실패 기록 보존, 테스트·누출 검사·수치 smoke 통과 |

현재 공개 Dev의 구성 수정 분석과 AI 사용×질문 허용의 2×2 비교는 탐색 단계다. 비AI 기준선 구현·Train 검증과 L40S 6,720경로 비교를 완료했다. [원래 문서의 주 손실](ai-comparison.md)은 질문 허용 시 비AI 72.1592, AI 20.9941이며, 문서 혼입·질문 금지에서는 AI가 악화됐다. 유리한 조건만 성공 기준으로 고르지 않는다.

[참여자 실험](human-study-guide.md)은 모집·동의·배정·과제·분석을 준비하고 자동 브라우저 리허설을 통과했다. 실제 사람은 아직 0명이다. 기본 128명은 참여자 평균 0.5 표준편차 효과에 대한 계획 가정이며, 경제적 최소 효과가 검증된 표본 수가 아니다. 새 출처 확증·실제 사람의 효과 측정은 후속 과제다.

## 과거 수치 기준의 보존

- ABCD 도구·인자·호출 precision 각각 90%는 보조 도구 실험의 목표다. Newsvendor 주 연구의 성공 기준으로 사용하지 않는다. 미달 결과와 과정은 [structured-history.md](structured-history.md) 및 [통합 전 문서 원본](evidence/artifacts/research-documents-before-economics-v1.tar.xz)에 보존한다.
- 생성 총손실 240.35 미만은 원래 120개 Test와 당시 손실 정의에 대한 기존 기준이다. 이전 모델의 243.6274는 미달이며, 새 모델·판매 환경·문서 혼입 조건의 성과로 덮어쓰지 않는다.
- 통제 문서의 모수·근거 100%는 실제 조직 문서의 효과 증거가 아니다. 최근 혼입 조건의 초기 정확도도 90% 미만이며 개선 과제로 남는다.
- 검정력 설계에 쓸 경제적으로 중요한 최소 효과는 아직 미확정이다. 관측 결과에 맞춰 유리한 기준을 사후 선택하지 않는다.

# 공개 Train 범위를 복원한 모수 구성 학습

직전 [보존 손실 실험](language-retention.md)은 모수 상태 오류를 줄였지만 공개 TAT-QA Dev 정답이 16/48에서 11/48로 떨어져 채택하지 않았다. 이번 비교는 같은 작은 모델에서 공개 문서의 학습 범위를 복원한다. 범용 도구나 ABCD를 주 평가에 다시 넣는 변경은 아니다.

## 확인한 학습 노출과 Train 진단

과거 문서 확장 학습과 그 후속 replay는 실제 완료된 각 epoch에서 TAT-QA 13,095개 주석을 처리했다. 원시 사례 목록과 scale 주석 적용 횟수가 일치한다. 이 자료는 고유 관측 입력 13,090개·출처 2,177개다. 반면 직전 보존 실험에서는 고유 입력 144개·출처 36개를 반복해 epoch당 432개 TAT-QA 사례만 처리했다.

같은 L40S에서 부모와 직전 후보를 Train 입력으로 대조했다. 자료 선택은 입력과 고정 seed로 먼저 정하고 이후 Train 주석으로 채점했다. 가중치는 갱신하지 않았고 Dev·Test는 사용하지 않았다.

| Train 진단 | 부모 | 직전 보존 후보 |
| --- | ---: | ---: |
| 반복 학습한 기존 TAT-QA 144개, 엄격 정답 | 79 | 94 |
| 그 밖의 확장 TAT-QA 표본 512개, 엄격 정답 | 251 | 236 |

추가 표본은 467개 출처에 속한다. 작은 반복 표본의 개선과 더 넓은 기존 학습 자료의 퇴행이 함께 나타났다. 이 결과는 일반화 성능이나 망각의 유일한 원인을 입증하지 않는다.

확장 표본에서 감소한 정답 15개 중 14개는 단일 span 추출에서 발생했다. 그 유형은 219개 중 163→149개였고, 산술은 204개 중 88→87개였다. 따라서 이 표본의 퇴행을 산술 연산만의 문제로 볼 수 없다. 현재 단일 필드 head가 직접 표현하지 않는 여러 span·개수 응답도 전체 점수에 포함되며, 두 모델 모두 그 89개에서는 정답이 없었다. 전체 TAT-QA 해결과 발주 모수 구성의 성과를 동일시하지 않는다.

고정 Train 64개씩의 첫 입력에서 계산한 encoder gradient도 기록했다. 모수 구성 gradient와 공개 추출 gradient의 cosine은 작은 표본에서 −0.0880, 확장 표본에서 +0.0763이었다. 한 국소 표본의 방향 차이만으로 두 과제가 항상 충돌한다고 결론 내리지 않는다. 진단 전체는 55.21초였고 모델 가중치는 전후 정확히 같았다.

## 비교 설정

[설정](../configs/l40s-research-coverage-v1.json)은 기존 선택 모델 `forecast-v1`에서 시작한다. 원래 모수 Train 9,536개와 공개 Train 13,725개를 각각 한 번씩 사용하는 23,261개 사례를 두 epochs 학습한다. 같은 작은 공개 표본을 반복하던 비율 설정을 제거했다. 공개 자료에는 TAT-QA 13,095개 주석과 기존 ContractNLI·CUAD·OR-ShARC가 포함된다.

ModernBERT encoder·head·학습률·두 epochs·고정 교사의 보존 손실 가중치 4.0은 직전 비교와 같다. GRU도 그대로 고정한다. 연구 Train의 사례 순서와 입력·환경, 공개 Dev의 입력·주석, 검색 collection이 이전 기록과 정확히 같음을 확인했다. 모든 원래 Train 사례를 유지하지만 공개 사례 수와 optimizer 갱신 수가 늘므로 같은 계산량의 자료 효과 비교라고 표현하지 않는다.

정확히 같은 입력이 중복된 Train 5쌍의 주석도 점검했다. 한 쌍은 식의 뒤쪽 공백만 달랐고, 나머지 네 쌍은 답이나 단위가 충돌했다. 해당 8개 행은 전체 TAT-QA Train 13,095개에 포함된다. 이번 등록된 실행의 자료를 중간에 수정하지 않았으며, 원문 주석과 충돌 기록을 보존한다. 위 656개 Train 진단에는 이 충돌 행이 없었다. 출처 분리 검사 통과를 모든 주석의 정합성 보장으로 해석하지 않는다.

모수 학습 후보는 기존 연구 Dev 기준으로 선택한다. 선택된 구성기를 고정한 뒤 실제 자기 예측 상태의 Train rollout으로 행동 가치를 두 번 다시 학습한다. 전체 후보의 채택은 공개 추출, 모수·근거, 필요한 질문과 회복, 잘못된 발주 진행, 실제 전달된 분포·모수의 발주 손실을 함께 확인한다. 기존 Test와 별도 판매 출처 27개는 학습·선택에 사용하지 않는다.

## 완료된 학습과 주 평가

L40S 학습·주 평가는 2,123.87초(35분 24초), 최대 GPU 할당 30.80 GiB로 완료됐다. 파라미터 수는 151,848,374개로 변하지 않았다. 첫 epoch는 모수·근거 정확도를 유지했지만 선택 점수를 개선하지 못해 제외했고, 원시 상태 오류를 12→5개로 줄인 두 번째 epoch를 선택했다. 원시 상태 오류의 분모는 792개 관측·응답 상태의 3,168개 필드다.

| 원래 Dev | 기존 선택 모델 | 작은 공개 표본 보존 | 확장 공개 Train 복원 |
| --- | ---: | ---: | ---: |
| 원시 모수 상태 오류 / 3,168 | 12 | 5 | 5 |
| TAT-QA 엄격 정답 / 48 | 16 | 11 | 15 |
| ContractNLI 상태 정답 / 72 | 44 | 45 | 35 |
| 판매 필요한 질문·응답 후 회복 / 336 | 336 | 336 | 336 |
| 판매 평균 총손실, 완전 관측 기간 | 24.3925 | 24.3925 | 24.3925 |
| 생성 60사례 평균 총손실 | 147.6813 | 146.7471 | 148.3549 |

판매·생성의 순차 실행 후 모수·근거 정확도는 100%였으며 잘못된 발주 진행은 없었다. 판매의 불필요한 질문과 모수 누락 상태의 종료도 0건이었다. 그러나 공개 문서 능력과 생성 총손실이 기준 모델보다 나빠 **전체 후보를 채택하지 않는다.** 기존 `forecast-v1`이 계속 선택 모델이다. 자료를 넓히면 모든 기능이 함께 보존된다는 근거를 얻지 못했다.

자기 상태의 새 rollout은 두 번 모두 924개 학습 표적을 만들었다. 각 수집 뒤 10·20 epochs에서 평가한 가치 head 네 후보는 기존 선택 점수를 개선하지 못해 모두 제외했다. 최종 모델은 선택된 언어 후보의 기존 가치 head를 유지하며, 새 가치 학습의 추가 이점을 주장하지 않는다.

생성 총손실 증가는 한 출처의 한 사례에서 생겼다. 이전에는 부족 비용 `b`를 질문하고 발주했지만 새 후보는 바로 발주했다. 60건 평균으로 요청 비용은 0.10625 줄고 종료 손실은 0.77985 늘어 총손실이 0.67360 증가했다. 이 생성 과제는 불확정 모수의 허용 범위 안에서 강건 발주를 할 수 있으므로, 질문 생략을 곧바로 잘못된 발주 진행으로 세지는 않는다. 판매 경로의 필수 모수 요청 기준과 구분한다.

해당 사례의 첫 관측 입력과 구성된 값·근거·상태·유형·식·발주량·불확실성 집합은 전후 정확히 같았다. 가치 head 자체의 가중치도 부모·두 언어 후보·최종 모델에서 같았다. 그런데 다음 행동은 `b` 질문에서 발주로 바뀌었다. 즉, 구성한 모수의 오류만으로 설명할 수 없는 행동 변화가 있다. 기존 가치 head가 갱신된 encoder 표현에 의존한다는 점을 후속 개선에서 다뤄야 하며, 이 한 사례로 모든 질문 오류의 원인을 일반화하지 않는다.

별도 L40S 후보 대조는 180.24초였다. 변형 학습을 제공하지 않은 기존 Train 출처 19개의 1,259개 상태·5,036개 필드에서 금액 오류는 부모 1,902개, 첫 후보 41개, 두 번째 후보 57개였다. 첫 후보의 TAT-QA 정답은 16/48을 유지했지만 ContractNLI는 38/72로 낮아져 이 후보도 공개 능력을 모두 보존하지 못했다. 선택·최종 모델은 두 번째 언어 후보와 전체 가중치가 같았고 공개 Dev 원시 출력도 주 실행과 정확히 일치했다. 두 언어 후보 모두 encoder가 갱신됐고 GRU는 부모와 정확히 같음을 확인했다.

각 언어 epoch의 모델, 마지막 언어 optimizer, 모든 가치 head 후보·optimizer와 원시 rollout을 보존한다. 별도 후보 대조와 가중치 보존 검증은 주 학습·평가 시간에 포함하지 않는다.

테스트 286개, Ruff·format 검사, 출처·입력 분리 검사 4종, 수치 smoke 30개가 통과했다. [전체 결과·원시 기록·모델 hash](evidence/research-replay-coverage-results.json)는 학습 자료 노출, 실패한 후보, 손실 분해, 주석 충돌까지 포함한다. 완전한 후보 가중치와 optimizer는 hash를 검증한 로컬 archive에 보존하며, 공개 artifact에는 원시 예측·rollout·설정·소스·소형 가치 head 후보를 포함한다. 기존 공개 추론 release는 교체하지 않는다.

판매 Dev의 정확한 손실은 완전 관측 기간 5개 × 생성 조건 7개이며, 원래 생성 Dev는 60사례·12개 출처다. 기존 Train 출처의 변형 문서 진단도 부모 학습과 독립적이지 않다. 이 실험으로 실제 조직 업무의 효과나 잠재 수요분포의 calibration을 입증하지 않는다.

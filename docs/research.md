# AI의 정보처리와 매니저 판단이 발주 의사결정에 미치는 영향

2026-10-10 갱신. 이 문서가 현재 연구계획의 기준이다. Word 배포본은 [proposal.docx](proposal.docx), 실행·식별 명세는 [protocol.md](protocol.md), 과거 기록은 [experiment-history.md](experiment-history.md)에 둔다. 문서·판매 이력으로 Newsvendor 모수를 구성하고 부족한 정보를 매니저에게 묻는 원래 범위를 유지한다.

## 1. 연구 목적과 기여

연구 질문은 **AI가 의사결정에 필요한 정보를 어떻게 개선하며, 어떤 경제적 조건에서 그 개선과 매니저 질문이 발주 손실을 줄이는가**이다. 수리 모형으로 오류와 정보 요청의 경제적 경로를 설명하고, 통제 실험과 회귀분석으로 효과의 크기·이질성·한계를 측정한다. ModernBERT와 작은 수요 GRU는 이 관계를 관측하는 고정된 실험 도구로 사용한다. 추가 모델 개발은 분석에서 확인한 병목과 연결할 때 수행한다.

예측과 보수를 정하는 판단의 구분은 Agrawal 등의 연구 [1]와 연결된다. 예측 정확도보다 후속 의사결정 손실을 평가하는 관점은 Elmachtoub와 Grigas [2]에 근거한다. 이 연구의 분석 대상은 문서에서 얻는 사실, 판매에서 추정하는 수요, 매니저가 선택하는 선호가 서로 다른 경로로 같은 발주 결정에 들어가는 과정이다. 이 결합만으로 학술적 신규성이 입증됐다고 주장하지 않으며, 후속 문헌 검토와 새로운 검증이 필요하다.

현재 사람 참여자는 0명이다. 매니저 응답은 통제 환경의 응답이다. 실제 사람의 신뢰·조언 수용·판단 변화·조직 생산성에 관한 주장은 참여자 또는 현장 실험의 후속 범위다.

## 2. 수리 모형

### 2.1 정보와 의사결정 기준

수요를 D, 발주량을 q, 경제 모수를 θ=(F,c,p,v,b)로 둔다. F는 수요분포, c는 원가, p는 판매가, v는 잔존가치, b는 단위 부족 비용이다. c·p·v는 적용 조건이 있는 사실, F는 추정, b는 관리자가 정한 평가 기준으로 구분한다. 실제 문서의 역할에 따라 b가 이미 확정된 정책일 수도 있다.

AI는 관측 정보 I로부터 모수·근거·누락·충돌 상태를 구성한다. 이미 본 원문과 응답만 I에 포함한다. 매니저가 아직 선택하지 않은 선호를 AI가 사실처럼 확정하지 않는다. 통제 실험의 기준 선호 b는 처치와 무관하게 사전에 고정하되, 미선택 상태에서는 질문을 통해 확인해야 한다. 실제 참여자의 선호 자체가 AI 때문에 바뀌는 연구는 별도 설계가 필요하다.

### 2.2 발주 손실과 이익

과잉 비용 Cₒ=c−v, 부족 비용 Cᵤ=p−c+b를 둔다. x⁺=max(x,0)일 때:

\[
\ell(q,D;\theta)=C_o(q-D)^+ + C_u(D-q)^+,
\qquad R(q;\theta)=\mathbb E_F[\ell(q,D;\theta)].
\]

완전한 모수 정보를 아는 기준 발주량은 q*=argmin R(q;θ)다. 미래에 실현될 D까지 미리 아는 결정과 구분한다. 연속 수요, Cₒ>0, Cᵤ>0, 발주 제약에 걸리지 않는 내부해에서는:

\[
\alpha=\frac{p-c+b}{p-v+b},\qquad q^*=F^{-1}(\alpha).
\]

정수·상하한·이산 수요에서는 공통 optimizer로 직접 최소화한다. 총손실은 실제 발주 손실 또는 사전에 정의한 보류 손실에 질문 비용을 더한다. 기존 생성 환경의 regret·보류·잘못된 진행 벌점과 판매 환경의 실현 수요 손실은 [실험 명세](protocol.md)처럼 구분해 보존한다.

경제적 평가 이익을 Π=p min(D,q)+v(q−D)⁺−cq−b(D−q)⁺로 두면 ℓ=(p−c)D−Π다. 같은 사례의 정책 차이는 동일한 기준 수요·선호 아래에서 비교한다. b가 서비스 수준의 그림자 비용이면 Π는 회계상 현금 이익과 다르다. 현금 이익과 서비스 페널티·질문 비용을 각각 보고한다. 생성 금액으로 실제 기업의 이익 증가를 주장하지 않는다.

### 2.3 모수 오류의 경제적 전달

F와 α의 작은 오차를 δF, δα라고 하고 f(q*)>0인 매끄러운 내부해를 가정하면, 최적 조건을 1차 전개해 다음 근사를 얻는다.

\[
\hat q-q^*\approx\frac{\delta\alpha-\delta F(q^*)}{f(q^*)},
\qquad
R(\hat q;\theta)-R(q^*;\theta)
\approx\frac{p-v+b}{2f(q^*)}\{\delta\alpha-\delta F(q^*)\}^2.
\]

또한 ∂α/∂b=(c−v)/(p−v+b)²다. 이 식은 어떤 모수의 오류인지, 발주 분위수 주변의 분포가 어떤지에 따라 같은 정답률 개선의 경제적 가치가 달라질 수 있음을 설명한다. 정확도 상승률에 손실 감소율이 반드시 비례한다고 가정하지 않는다. 0 수요 질량, 이산 지지점, 경계해에서는 이 미분 근사를 적용하지 않고 실제 optimizer의 유한 변화로 확인한다.

이 결과는 제시한 가정에서의 표준 최적 조건 전개이며 새로운 정리로 주장하지 않는다. [분석 코드](../src/newsvendor/decision_effects.py)의 연속 균등수요 검사로 곡률·선호 민감도 식을 수치 확인한다. 이 검사는 학습 AI의 성능 측정이 아니다.

### 2.4 질문의 가치

V₀(I)를 현재 정보로 결정할 때의 최소 조건부 기대손실이라고 하자. 질문 a 후 응답 Zₐ를 받고 바로 결정하는 경우의 정보 가치는:

\[
\operatorname{EVSI}_a(I)
=V_0(I)-\mathbb E[V_0(I,Z_a)\mid I].
\]

한 번 질문한 뒤 결정하는 조건에서는 EVSI가 질문 비용 κₐ보다 클 때 질문이 유리하다. 여러 질문과 예산·보류가 있으면 잔여 상태 B에서 다음 Bellman 식으로 확장한다.

\[
V(B)=\min\left\{C_{\mathrm{order}}(B),C_{\mathrm{hold}}(B),
\min_{a\in\mathcal A(B)}[\kappa_a+\mathbb E\{V(B')\mid B,a\}]\right\}.
\]

응답 분포에는 무응답·부분 응답·잘못된 응답을 포함한다. 위 식은 반응 모형과 믿음이 주어진 규범적 기준이다. 현재 학습 정책이 최적 정보 가치를 정확히 안다고 가정하지 않는다. 생성기의 숨겨진 응답 집합과 참모수를 아는 planner는 채점용 상한·진단이며 배포 가능한 정책 비교군이 아니다.

## 3. 검증할 가설

다음은 새 확증 결과가 아니라 후속 실험에서 검증할 가설이다. 기존 Dev를 보고 선택한 가설이라는 사실도 기록한다.

| 가설 | 사전 조건과 예상 관계 | 반증·제한 |
| --- | --- | --- |
| H1 정보의 경제적 민감도 | 중요한 비용비·발주 분위수의 오류를 줄일수록 손실 감소가 커진다 | 전체 정답률만 개선되고 관련 분위수·모수가 같으면 손실 차이가 없을 수 있다 |
| H2 질문의 순가치 | 정보 누락·충돌이 있고 응답이 신뢰할 만하며 비용이 낮으면 질문 허용의 순효과가 커진다 | 정확한 정보가 이미 있거나 무응답·비용이 크면 질문이 도움이 되지 않을 수 있다 |
| H3 AI와 질문의 상호작용 | AI의 상태 파악이 필요한 질문을 잘 선택하게 하면 두 기능의 결합에서 추가 손실 감소가 생긴다 | AI가 질문을 대체하거나 단순 규칙과 결과가 같으면 보완성이 약하거나 없다 |

질문 횟수·정확도는 작동 경로를 보여 주는 결과 지표다. 총효과 회귀에 사후 통제변수로 자동 투입하지 않는다. 처치 후 변수에 조건을 걸면 총효과가 왜곡될 수 있다 [3]. 메커니즘은 모듈을 통제해 바꾸는 추가 실험으로 확인한다.

## 4. 효과의 식별과 회귀

### 4.1 현재 실행한 분석: 구성 수정 효과

공개 Dev의 parent와 scoped는 모두 AI를 포함한다. 같은 사례·문서 조건·추가 응답 누락 없음에서 결과를 짝지어 ΔY=Y(scoped)−Y(parent)를 만든다.

\[
\Delta Y_{ic}=\beta_0+\sum_{k\ne\mathrm{original}}\beta_k\mathbf1(c=k)+\epsilon_{ic}.
\]

이 포화 회귀의 적합값은 조건별 짝지은 평균 차이와 같다. 회귀라는 형식이 새로운 발견이나 인과 식별을 추가하지 않는다. 원래 사례의 공통 특성은 차분에서 제거되지만, Dev 재사용·모형 선택·적은 출처 수의 한계는 남는다. 전체 AI 도입 효과, 매니저 질문 허용 효과, 인간 행동 효과는 이 분석으로 식별되지 않는다.

사례 가중 평균, 출처별 평균, 출처를 동일하게 가중한 효과, 한 출처씩 제외한 범위를 함께 보고한다. 이 범위는 신뢰구간이 아니다. 소수 군집과 반복 관측에서는 통상 표준오차가 정밀도를 과장할 수 있으므로 [4], 현재 탐색 보고서에는 p값과 신뢰구간을 내지 않는다. 이 결정은 추후 유리한 유의성을 얻기 위해 바꾸지 않는다.

### 4.2 실행한 파일럿: AI 사용 × 질문 허용

관측 문서의 규칙 추출과 검열 로그정규 수요 추정을 사용하는 비AI 기준선을 구현했다. Train 154사례·13출처에서 검증한 뒤 같은 입력의 기존 Dev 336사례·8출처에서 A∈{0,1}(정의한 AI 묶음), H∈{0,1}(질문 허용)을 교차했다. 문서 조건 다섯 개를 포함한 6,720경로를 L40S에서 실행했다. optimizer·질문 규칙·비용·예산·응답 환경은 공통이다. 신경망 가중치는 고정했다.

\[
Y_{ij}=\alpha_i+\beta_A A_j+\beta_H H_j+
\beta_{AH}A_jH_j+\varepsilon_{ij}.
\]

주 분석은 관리자 기준 b가 이미 선택된 사례다. b 미선택 사례는 별도 층이다. 원래 문서의 정확한 손실은 같은 25조건·고유 수요 기간 5개·출처 4개에서 계산된다. 평균 총손실은 A0H0 409.3229, A0H1 72.1592, A1H0 399.0899, A1H1 20.9941이다. βA=−10.2330, βH=−337.1636, βAH=−40.9321이며, 질문 허용 상태의 AI−비AI 차이는 −51.1651이다.

이 차이는 정의한 비AI 기준선과 고정 AI 묶음의 비교다. 원래 문서에서는 두 방법의 모수·근거·질문이 같으므로 발주 손실 차이는 수요 추정 경로에서 나온다. 정형 생성 문서에서는 비AI 규칙이 더 정확한 조건도 있다. 상품·기간·버전 혼입에서 AI는 불필요 질문이 늘고, 질문을 금지하면 비AI보다 손실이 높다. 전체 표·출처 민감도·원시 기록은 [ai-comparison.md](ai-comparison.md)에 있다.

H0의 원래 사례 80%는 누락 때문에 보류하므로 큰 질문 효과에는 보류 해소가 포함된다. 이를 사람과 AI의 일반적인 보완성으로 해석하지 않는다. 단일 비AI 수요 추정 방식이 모든 통계적 기준선을 대표하지 않으며, 이미 개발한 Dev와 적은 출처의 결과는 확증이 아니다. p값·신뢰구간은 보고하지 않았다. 처치 전 환경 X에 따른 이질성은 새로운 자료에서 A×X 등을 미리 정해 검증할 후속 대상이다.

### 4.3 준비한 참여자 실험: 사람의 AI 정보 지원 효과

사람을 모집하면 바로 사용할 한국어 브라우저 실험을 구현했다. AI 없음과 AI 있음에 참여자 단위 1:1 배정하며 양쪽 모두 문서·판매 이력·계산 보조·매니저 질문을 사용한다. AI군에 고정 모델의 모수·근거·수요·발주량 제안이 추가된다. 최종 결정자는 참여자다. 매니저 응답은 프로그램이 제공한다. 사람의 AI 사용을 무작위 배정하는 접근은 Noy와 Zhang [5]의 연구와 관련되지만, 글쓰기의 효과를 발주 과제로 옮겨 가정하지 않는다.

동의·이해 확인 뒤 네 명 단위로 두 명씩 배정하고, 연습 2개와 순서를 무작위화한 본 과제 8개를 제공한다. 공통 질문은 과제당 최대 2회·회당 4점, 보류는 400점, 발주량은 0~70이다. 주 결과는 본 과제별 기대 regret 또는 보류 비용과 질문 비용의 합을 400으로 나눈 참여자 평균이다. 완전한 배정 결과에서는 다음 블록 조정 회귀와 블록 내 무작위화 검정을 사용한다.

\[
\bar Y_i=\alpha+\tau\operatorname{AI}_i+
\sum_{b\ne 1}\eta_b\mathbf1\{\operatorname{block}(i)=b\}+u_i.
\]

반복 과제를 독립 참여자로 세지 않는다. 기본 128명은 참여자 평균의 0.5 표준편차 차이에 대해 양측 5%·약 80% 검정력을 가정한 계획 수다. 실제 사람의 분산과 경제적 최소 효과를 측정한 결과가 아니다. 모집 전 작은 목표를 정하면 탐색 파일럿으로 구분한다. 중단·누락이 있으면 배정 효과의 가능한 범위와 완료자 기술 통계를 제시하며 누락을 무시하는 p값은 계산하지 않는다.

실제 사람 데이터는 아직 없다. 4명의 자동 브라우저 리허설은 기능 검사다. 과제는 생성한 고정 사례이며, 현재 AI는 새 수요 이력에서 과다 발주하는 사례가 있다. 그 제안을 정답으로 교정하지 않고 사용하므로 유익·영효과·악화가 모두 가능한 실험이다. 실제 조직·실무 매니저 전체로 일반화하지 않는다. [운영 안내와 Word](human-study-guide.md), [기계 판독 명세](../experiments/participant/protocol.json), [준비 검증](evidence/human-experiment-readiness.json)에 모집·동의·접속·내보내기·분석 절차가 있다. 로컬 계획은 외부 사전등록이나 기관 승인을 뜻하지 않는다.

## 5. 현재 모델과 검증된 범위

| 항목 | 현재 상태 |
| --- | --- |
| 선택 모델 | 공개 recovery-v1 가중치와 scoped 모수 선택 경로; 약 151.88M 파라미터 |
| 언어·수요 경로 | 학습한 ModernBERT-base + 모수·근거·상태 head + 2층 GRU(hidden 128) |
| 결정 | 관측 상태에서 질문·조회·보류·optimizer 전달; 문장 생성 불필요 |
| 최신 비교 | 가중치를 고정한 L40S AI×질문 2×2 파일럿 완료; Train 616경로·Dev 6,720경로 |
| 원래 생성 Dev | 평균 총손실 147.6813 유지; 60사례·12 family |
| 원래 판매 Dev | 평균 총손실 24.3925 유지; 정확한 손실 5기간·4출처·35조건 |
| 문서 혼입 | 초기 모수 56.50~57.58%→84.72~85.29%, 근거 42.25~43.67%→79.72~80.47% |
| 질문·실제 출력 | 세 혼입 조건의 판매 불필요 질문 454~475→189~190; 종료 손실·총손실 감소 |
| 추가 가치 학습 | 여러 통제 판매 비교에서 단순 규칙의 추가 이점을 넘어서지 못함 |
| 기존 생성 Test | 이전 모델 243.6274; 기존 240.35 기준 미달, 새 모델 결과로 표시하지 않음 |

[구성 수정의 전체 결과](parameter-decoding.md), [수요 모델 선택](demand-selection.md), [선택 가중치](model-bundle.md), [새 출처의 과거 평가](retail-holdout.md)를 참조한다. 생성 Dev·판매 Dev·문서 혼입의 과거 수치는 기존 고정 측정이며 새 2×2의 주 분석과 분모가 다르다. 앞선 구성 수정 회귀의 결과·자료 hash는 [decision-effects.md](decision-effects.md), 새 비AI 비교는 [ai-comparison.md](ai-comparison.md)에 둔다.

판매 336사례의 질문 지표와 35조건의 정확한 손실 분모를 섞지 않는다. 품절 판매를 잠재 수요로 대체하지 않는다. 문서 조건·응답 조합·seed의 반복은 독립 출처 수를 늘리지 않는다. 이미 동결 평가한 27개 출처도 새 확증 표본으로 재명명하지 않는다. 생성 문서·비용·응답의 성과를 실제 조직 효과로 주장하지 않는다.

## 6. 진행 순서와 완료 기준

1. 수리 모형·기존 측정을 통합하고 공개 Dev의 탐색 회귀와 수치 항등식 검증을 완료했다.
2. 비AI 기준선의 관측 입력 구현·Train 검증과 공통 정책의 AI×질문 2×2 파일럿을 완료했다. 원시 경로와 160경로 독립 재현을 보존했다.
3. 참여자 실험의 동의·무작위 배정·과제·저장·분석을 준비하고 소프트웨어 리허설을 완료했다. 모집 후 실제 사람의 자료를 수집한다.
4. 후속 확증에서는 독립적인 새 출처 또는 새로운 참여자·과제, 경제적으로 중요한 최소 효과, 표본·제외·분석계획을 고정한다. 개발에 쓴 Dev·기존 holdout·파일럿을 새로운 확증으로 재명명하지 않는다.

연구의 완료는 유의한 양의 효과나 임의의 정확도 달성을 전제로 하지 않는다. 추적 가능한 자료, 유효한 비교군, 효과와 불확실성, 영효과·악화 조건까지 설명할 수 있는지가 기준이다. 과거 성능 기준의 적용 범위는 [performance-goal.md](performance-goal.md)에 보존한다.
